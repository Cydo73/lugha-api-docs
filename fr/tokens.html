Tokens et langues¶

Les modèles ne lisent pas les mots. Ils lisent des tokens, qui sont des fragments de texte. Vous payez pour les tokens, votre limite max_tokens est mesurée en tokens, et un nombre plus élevé de tokens prend plus de temps à traiter. Il est donc utile de savoir combien de tokens votre texte utilisera avant de l’envoyer.

Pourquoi une même idée peut coûter des quantités différentes¶

Un tokenizer conçu principalement autour du texte anglais découpe souvent les mots d’autres langues en davantage de fragments. Une même phrase dans deux langues peut donc utiliser un nombre différent de tokens, même si son sens est identique. Si vous développez pour plusieurs langues, vérifiez le nombre de tokens pour chacune au lieu de supposer qu’ils sont identiques.

Comptez les tokens avant l’envoi¶

POST /v1/tokens/count renvoie le nombre de tokens pour un fragment de texte.

Note

Lugha utilise volontairement un tokenizer simple. Il découpe chaque mot en fragments de quatre caractères au maximum. Cela rend les résultats faciles à expliquer et à reproduire. Il ne décrit pas la manière dont un modèle réel compte les tokens. Considérez donc les nombres ci-dessous comme une démonstration de l’endpoint, et non comme une mesure.

Comptez les tokens d’une phrase anglaise :

curl "$LUGHA_BASE_URL/v1/tokens/count" \
  -H "Authorization: Bearer $LUGHA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Good morning, my friend."}'

{"token_count": 6, "word_count": 4, "tokens_per_word": 1.5}

Maintenant, une phrase en swahili :

curl "$LUGHA_BASE_URL/v1/tokens/count" \
  -H "Authorization: Bearer $LUGHA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text": "Habari ya asubuhi, rafiki yangu."}'

{"token_count": 9, "word_count": 5, "tokens_per_word": 1.8}
token_count

Le nombre de tokens dans le texte.

word_count

Le nombre de mots, séparés selon les espaces.

tokens_per_word

token_count divisé par word_count, arrondi à deux décimales. Utilisez-le pour comparer des textes de longueurs différentes.

Comment les tokens apparaissent ailleurs¶

L’objet usage dans une réponse /v1/generate indique les mêmes nombres pour une requête réelle : prompt_tokens pour ce que vous avez envoyé et completion_tokens pour ce qui a été renvoyé.

max_tokens limite uniquement completion_tokens. Il n’inclut pas votre prompt. Si le modèle atteint la limite, la réponse se termine avec finish_reason défini sur length.

Comptez d’abord les tokens de votre prompt si vous souhaitez estimer la taille d’une requête avant de l’envoyer.
