Àṣìṣe¶

Nígbà tí ìbéèrè kan bá kuna, ara ìdáhùn máa ń ní ìṣètò kan náà, ohunkóhun tí ó bá fa ìṣòro náà.

{
  "error": {
    "type": "invalid_request",
    "message": "model: Field required",
    "request_id": "req_502924837fc6"
  }
}
type

Ẹ̀ka tí ẹ̀rọ lè kà. Lo iye yìí láti pín ìhùwàsí kóòdù rẹ.

message

Àlàyé tó rọrùn fún ènìyàn. Ṣàfihàn rẹ̀ nínú àwọn log, ṣùgbọ́n má ṣe túpalẹ̀ rẹ̀. Ọ̀rọ̀ náà lè yí padà.

request_id

ID ìbéèrè yìí. Ó tún wà nínú àkọsílẹ̀ ìdáhùn X-Request-ID. Sọ ọ́ nígbà tí o bá kan sí ẹ̀ka ìrànwọ́, kí o má sì ṣe fi API key rẹ ránṣẹ́ láé.

Àwọn irú àṣìṣe¶

type

Ipò

Ohun tí ó túmọ̀ sí

Gbìyànjú lẹ́ẹ̀kansi?

authentication_required

401

Àkọsílẹ̀ Authorization kò sí tàbí ó ní ìṣètò tí kò tọ́.

Rárá

invalid_api_key

401

A kò mọ̀ key náà.

Rárá

invalid_request

400

Field kan kò sí tàbí ó ní iye tí kò tọ́. Ìfiranṣẹ́ náà ń tọ́ka sí field náà.

Rárá

unsupported_language

400

Model kò ṣe àtìlẹ́yìn fún èdè yìí. Ìfiranṣẹ́ náà ń ṣàkójọ àwọn èdè tí ó ṣe àtìlẹ́yìn fún.

Rárá

unsupported_region

400

Ẹkùn náà kò sí lára ke, ug, ma tàbí mu.

Rárá

model_not_found

404

Kò sí model tí ó ní ID náà. Ṣàkójọ àwọn model pẹ̀lú GET /v1/models.

Rárá

not_found

404

Kò sí endpoint ní ọ̀nà yẹn.

Rárá

method_not_allowed

405

Endpoint náà kò gba HTTP method yẹn.

Rárá

rate_limit_exceeded

429

O ti lo gbogbo àwọn ìbéèrè rẹ fún ìṣẹ́jú yìí.

Bẹ́ẹ̀ni, lẹ́yìn Retry-After

internal_error

500

Ohun kan kò lọ dáadáa ní ẹ̀gbẹ́ iṣẹ́ náà.

Bẹ́ẹ̀ni, pẹ̀lú ìdádúró tó ń pọ̀ sí i

400, 401, 404 tàbí 405 túmọ̀ sí pé ìbéèrè náà fúnra rẹ̀ nílò àyípadà. Ríránṣẹ́ sí i lẹ́ẹ̀kansi láìyípadà yóò tún kuna.

Àwọn àpẹẹrẹ¶

Model tí kò ṣe àtìlẹ́yìn fún èdè tí o béèrè fún:

{
  "error": {
    "type": "unsupported_language",
    "message": "Model 'lugha-demo-small' does not support language 'am'. Supported: en, sw, lg.",
    "request_id": "req_183e64b5682b"
  }
}

Ìtúnṣe náà wà nínú ìfiranṣẹ́. Lo model tí ó ṣe àtìlẹ́yìn fún èdè náà, tàbí yan ọ̀kan lára àwọn èdè tí a ṣe àkójọ.

Àwọn ààlà ìwọ̀n ìbéèrè¶

API key kọ̀ọ̀kan lè ṣe ìbéèrè mẹ́wàá fún ìṣẹ́jú kan. Ìkà náà máa ń bẹ̀rẹ̀ padà ní ìbẹ̀rẹ̀ ìṣẹ́jú kọ̀ọ̀kan. Gbogbo ìdáhùn máa ń sọ fún ọ bí ìlò rẹ ṣe rí.

Àkọsílẹ̀

Ìtumọ̀

X-RateLimit-Limit

Iye àwọn ìbéèrè tí a gbà láàárín ìṣẹ́jú kan.

X-RateLimit-Remaining

Iye àwọn ìbéèrè tó kù nínú ìṣẹ́jú yìí.

X-RateLimit-Reset

Iṣẹ́jú-aaya mélòó kan ló kù kí ìkà náà bẹ̀rẹ̀ padà.

Nígbà tí o bá ti lo gbogbo àwọn ìbéèrè rẹ, èyí tó tẹ̀lé máa dá ipò 429 padà pẹ̀lú àkọsílẹ̀ Retry-After.

HTTP/1.1 429 Too Many Requests
Retry-After: 60
X-RateLimit-Limit: 10
X-RateLimit-Remaining: 0
X-RateLimit-Reset: 60
X-Request-ID: req_658e47454555

{
  "error": {
    "type": "rate_limit_exceeded",
    "message": "You have used all 10 requests for this minute. Retry in 60 seconds.",
    "request_id": "req_658e47454555"
  }
}

Dúró fún iye iṣẹ́jú-aaya tó wà nínú Retry-After, lẹ́yìn náà rán ìbéèrè náà sí i lẹ́ẹ̀kansi. Gbìyànjú lẹ́sẹ̀kẹsẹ̀ máa ń jẹ́ kí o lo púpọ̀ sí i nínú ààyè ìlò rẹ.

Tí o bá ń rí 429 lọ́pọ̀ ìgbà, dín ìgbà tí o fi ń rán àwọn ìbéèrè kù. Máa wo X-RateLimit-Remaining kí o sì dá dúró kí ó tó dé odo.

Ohun tí a lè gbìyànjú lẹ́ẹ̀kansi¶

Gbìyànjú 429 lẹ́ẹ̀kansi lẹ́yìn ìdádúró Retry-After. Gbìyànjú 500 àti àwọn àṣìṣe nẹ́tíwọ́ọ̀kì lẹ́ẹ̀kansi pẹ̀lú ìdádúró tó ń pọ̀ sí i, èyí túmọ̀ sí dídúró díẹ̀ síi lẹ́yìn gbogbo ìgbìyànjú tí ó kuna. Má ṣe gbìyànjú àwọn àṣìṣe mìíràn lẹ́ẹ̀kansi.

Production checklist náà ní client kan tó ń ṣe gbogbo ìwọ̀nyí nínú.
