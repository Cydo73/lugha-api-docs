API reference¶

This page is generated from the OpenAPI file, which is exported from the service code. When the API changes, this page changes with it.

All endpoints except /health need an API key. See Authentication.

POST /v1/generate¶

Generate text

Sends a prompt to a model and returns the response. The response includes an X-Data-Region header that echoes the region that processed the request.

Requires an API key.

Request body¶

Field

Type

Required

Description

model

string

Yes

ID of the model to use. List them with GET /v1/models.

prompt

string

Yes

The text you want the model to respond to. Length 1 to 4000 characters.

language

string

No

Language code of the prompt. Each model supports a different set. Default: "en".

max_tokens

integer

No

Upper limit on tokens in the response. Cannot exceed the model’s max_output_tokens. Default: 64. Minimum 1.

region

string

No

Where the request is processed: ke, ug, ma or mu. Default: "ke".

Example request body:

{
  "model": "lugha-demo-large",
  "prompt": "Habari, tafadhali nieleze Kampala ni nini.",
  "language": "sw",
  "max_tokens": 64,
  "region": "ug"
}

Responses¶

Status

Meaning

200

The generated text and token usage.

400

The request was invalid. Check the message field.

401

The API key is missing or not valid.

404

The model or endpoint does not exist.

429

Rate limit exceeded. Wait for the number of seconds in the Retry-After header.

A 200 response has these fields.

Field

Type

Description

id

string

Unique ID for this generation.

model

string

The model that handled the request.

language

string

The language code you sent.

output

string

The generated text.

finish_reason

string, one of stop, length

stop means the response ended naturally. length means it was cut off at max_tokens.

usage

Usage object

Token counts for this request.

The usage object has these fields.

Field

Type

Description

prompt_tokens

integer

Tokens in the prompt.

completion_tokens

integer

Tokens in the response.

total_tokens

integer

prompt_tokens plus completion_tokens.

Failures use the standard error body described in Errors.

GET /v1/models¶

List models

Requires an API key.

Responses¶

Status

Meaning

200

The models you can use.

401

The API key is missing or not valid.

429

Rate limit exceeded. Wait for the number of seconds in the Retry-After header.

A 200 response has these fields.

Field

Type

Description

data

array of ModelInfo object

The available models.

Each item in data has these fields.

Field

Type

Description

id

string

Model ID. Pass this as model when you generate text.

max_output_tokens

integer

Largest max_tokens value this model accepts.

languages

array of string

Language codes this model accepts.

Failures use the standard error body described in Errors.

POST /v1/tokens/count¶

Count tokens

Requires an API key.

Request body¶

Field

Type

Required

Description

text

string

Yes

Text to count tokens for. Length 1 to 20000 characters.

Example request body:

{
  "text": "Habari ya asubuhi, rafiki yangu."
}

Responses¶

Status

Meaning

200

The token count for the text.

400

The request was invalid. Check the message field.

401

The API key is missing or not valid.

429

Rate limit exceeded. Wait for the number of seconds in the Retry-After header.

A 200 response has these fields.

Field

Type

Description

token_count

integer

Number of tokens in the text.

word_count

integer

Number of words in the text, split on whitespace.

tokens_per_word

number

token_count divided by word_count, rounded to two decimals.

Failures use the standard error body described in Errors.
